# Unity3D战斗系统Demo

这是一个基于 **Unity URP** 的 3D 战斗演示项目，主要用于练习和展示 **角色控制、敌人 AI 行为、基础战斗系统** 以及 **项目模块化架构设计**。
项目以学习和实践为目标，重点关注系统结构的清晰性与功能拆分，而非完整商业化玩法。

---

##  项目目标
- 熟悉 Unity URP 渲染管线的基础配置与使用  
- 实践 3D 游戏中常见的角色控制与战斗流程  
- 通过模块化设计提高代码可读性与可扩展性  

---

##  负责的内容
- 使用 Unity URP 构建基础渲染管线与场景环境  
- 实现玩家角色的移动与基础攻击控制  
- 实现敌人基础 AI 行为逻辑（如追击、攻击、状态判断）  
- 实现战斗流程中的攻击判定与受击处理  
- 对项目逻辑进行模块化拆分，避免逻辑高度耦合  

---

##  核心功能说明
- **角色控制**：基于输入系统实现玩家移动与攻击行为  
- **敌人 AI**：通过状态判断控制敌人行为切换  
- **战斗系统**：基础攻击、受击与生命状态管理  
- **项目结构**：将玩家、AI、战斗等逻辑拆分为独立模块，便于维护和扩展  

---

##  技术栈
- Unity 3D  
- C#  
- Universal Render Pipeline（URP）
